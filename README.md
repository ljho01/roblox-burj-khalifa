# Build the Burj — 부르즈 할리파를 건설하세요

자재를 운반하고, 같은 서버의 플레이어와 828m 부르즈 할리파를 완성하는 Roblox 게임입니다. `./scripts/build.sh`로 `dist/Build-the-Burj.rbxlx`를 생성할 수 있습니다.

## 개발 종료 · 오픈소스 공개

2026-10-03에 프로젝트 개발을 종료했습니다. 소스, 빌드 스크립트와 테스트를 MIT 라이선스로 공개하며, 이 저장소는 보관용입니다. 추가 개발이나 지원은 제공하지 않습니다. 포크해서 자유롭게 사용하거나 수정할 수 있습니다.

생성된 Studio 파일, 실행 로그와 임시 파일은 저장소에 포함하지 않습니다. `docs/VALIDATION.md`는 2026-09-26 당시의 검증 기록이며, 기록에서 언급하는 로컬 로그는 공개 대상에서 제외했습니다.

## 손에 드는 장비와 방어

- 하단 슬롯과 숫자 키를 고정했습니다: **1 자재 / 2 뺨때리기 / 3 빠따 / 4 바나나**. 슬롯을 클릭하거나 터치해도 전환됩니다.
- 1번은 무기를 내려놓고 자재 운반으로 돌아갑니다. 무기를 들더라도 등 위 자재와 운반량은 유지되며, 피격 시에는 전부 떨어집니다.
- 보유하지 않은 무기 슬롯은 `20 R$ · 구매`로 표시합니다. 해당 숫자 키나 슬롯을 누르면 그 무기의 결제창이 바로 열립니다. 결제 요청만으로 장착되거나 지급되지 않으며, 보유 무기는 선택 후 클릭/터치로 사용합니다.
- 상대가 E를 누르며 빼돌리는 중에 뺨때리기나 빠따를 명중시키면 즉시 중단됩니다. 이미 챙긴 분홍 자재도 쓰레기통에 버리기 전에 맞히면 회수되어 건설 진행이 보존됩니다. 막은 플레이어와 상대에게 결과를 알려 줍니다.

## 바로 플레이하기

1. Rojo 7을 설치하고 `./scripts/build.sh`를 실행한 뒤, 생성된 `dist/Build-the-Burj.rbxlx`를 Roblox Studio에서 엽니다.
2. 상단 **▶ Test / Play** 버튼을 누릅니다.
3. **초록색 자재 받기** 구역으로 이동해 **E**를 누릅니다.
4. **노란색 타워 건설** 구역으로 가져가 **E**를 누르면 건설되고 코인을 받습니다.
5. **B / 장비 꾸러미**에서 운반력·속도를 올리거나 자동 작업자를 고용합니다.
6. **장난감 · 20 R$** 탭에서 뺨때리기·빠따·바나나 사용권을 구입하고 **꺼내기**로 장착합니다. 클릭/터치로 사용합니다. Studio에서는 **무료 체험 +1** 버튼으로 테스트할 수 있습니다.
7. 빈 가방으로 **보라색 자재 빼돌리기** 구역에서 **E를 끝까지 누르고 있으면** 바로 자재를 받습니다. 담는 개수에 따라 누르는 시간이 로그 함수로 늘어납니다. 분홍색 자재를 **자재 쓰레기통**으로 가져가 버려야 건설 진행에서 차감됩니다.

WASD로 이동, Space로 점프, 마우스로 카메라를 조작합니다. 모바일에서는 Roblox 기본 이동 조작과 화면 아래 행동 버튼 또는 현장 프롬프트를 사용합니다. 게임패드는 기본 이동과 **X** 프롬프트를 사용합니다.

편집 화면의 완성된 건물은 미리보기입니다. 플레이를 시작하면 공사 0단계에서 새로 시작합니다.

## 이번 업데이트

- 등에 메는 자재의 가로·높이·깊이를 각각 2배로 키워 한 개당 부피를 **8배**로 확대했습니다. 플레이어·친구 운반자·빼돌린 자재에 공통 적용하며, 쌓기 간격·받침대·내려놓기 간격도 맞췄습니다.
- **자재 빼돌리기**: 가방 용량만큼(기본 8개, 강화 시 최대 128개) 챙깁니다. **E 길게 누르기**를 완료하면 추가 대기 없이 받습니다. 시간은 `2.2 × ln(1 + 실제 담을 개수) / ln(9)`초입니다. 8개 약 2.2초, 32개 3.5초, 128개 4.9초이며, 손을 떼거나 움직이거나 맞으면 취소됩니다.
- 빼돌린 자재는 분홍색으로 표시됩니다. 웃는 얼굴의 분홍 쓰레기통까지 운반해 버릴 때만 타워에서 차감되고, 줄어든 층에 맞춰 외벽과 크레인도 내려갑니다.
- 여러 플레이어의 빼돌릴 자재를 따로 예약해 중복 차감을 막습니다. 운반 중 피격·사망·퇴장·현장 복귀 시 예약이 풀리며 건설 진행은 유지됩니다. 완공 후에는 진행을 되돌릴 수 없습니다.
- 빼돌린 자재로 건설 보상을 받거나 창고 자재와 섞을 수 없습니다. 빼돌리는 동안 진행 막대와 분홍 벽돌 비행, 쓰레기통에 버리는 애니메이션이 표시됩니다.
- 뺨때리기·말랑 빠따·바나나를 각각 **20 Robux / 1회 사용권**으로 추가했습니다. 손바닥·빠따는 앞의 가까운 상대에게 명중할 때만 차감하고, 바나나는 놓을 때 차감합니다.
- 맞거나 바나나에 미끄러지면 운반 자재를 전부 떨어뜨립니다. 자재가 흩어지고 머리 주변에 반짝이가 돌며, 약 1초 뒤 일어납니다. 체력·코인·이미 건설한 층에는 영향을 주지 않습니다.
- 바나나는 설치자를 제외한 상대 한 명에게 작동합니다. 90초 뒤 사라지고 플레이어당 2개, 서버당 32개로 제한됩니다.
- 구매 영수증과 사용 여부를 한 저장소 기록에 원자적으로 저장합니다. 영수증이 재전달되어도 중복 지급하지 않고, 재접속해도 남은 사용권을 유지합니다.
- 층을 올리면 크레인 기둥이 길어지고 운전석·팔·매달린 자재도 함께 올라갑니다. 완공 시 첨탑보다 높아지며 다음 공사에서 처음 높이로 돌아옵니다.
- 새 층 둘레에서 크림색·민트색 먼지 구름과 별 반짝이가 피어났다 사라집니다. 동시 건설 시에도 효과는 최대 128개 파트로 제한됩니다.
- 타워의 월드 높이를 **280 → 568스터드**로 키우고, 외벽 폭도 확대했습니다. 게임 내 완공 높이 표시는 기존과 같이 828m입니다.
- 48개 건설 구간에 총 144층의 외벽 밴드, 곡면 창틀, Y자 날개와 교차 후퇴 테라스, 12단 첨탑을 넣었습니다.
- 캐노피 입구, 분수 물결, 굽은 야자수 잎, 벤치·화단·석재 무늬, 지게차·창고의 세부 부품을 추가했습니다.
- 확대된 기단에 맞춰 투입 구역을 남쪽으로 18스터드 옮겼고, 최대 카메라 줌 거리를 420스터드로 늘렸습니다.

- 작업자를 고용하면 친구 목록에서 랜덤 아바타가 등장해 자재를 메고 창고와 건설 구역을 왕복합니다. 이름과 상태 말풍선은 표시하지 않습니다.
- 운반자는 플레이어마다 **1명**만 등장합니다. 업그레이드하면 같은 친구의 등에 자재가 2 → 4 → 6 → 최대 40개로 늘어나며, 8초마다 그만큼 운반합니다. 친구 목록·아바타를 불러오지 못하거나 친구가 없으면 기본 운반자가 대신합니다.
- 운반 자재 1개마다 등 위에 벽돌 1개가 보이며, 강화하면 8 → 14 → 최대 128개까지 높게 쌓입니다.
- 광장 가로·세로를 각각 두 배(352×348)로 넓혔습니다. 민트색 자재 창고와 노란 투입 구역은 약 115스터드 떨어져 있습니다.
- 자재를 내려놓으면 등에서 투입 구역으로 날아가 차곡차곡 착지합니다.
- 우윳빛·파스텔 패널, 둥근 버튼, 안전모와 벽돌 아이콘을 사용했습니다.
- 데스크톱 구간 표시는 화면 위쪽 8px에 붙였습니다. 좁은 화면은 Roblox 메뉴와 겹치지 않도록 배치합니다.

## 들어 있는 기능

- Y자 평면, 단계별 후퇴하는 유리 외벽, 첨탑이 있는 **48단계 부르즈 할리파**
- 두바이 광장, 주변 스카이라인, 타워크레인, 야자수, 분수, 자재 야적장
- 서버 공동 건설, 개인 코인·운반량·기여도·완공 횟수
- 운반력·이동 속도 업그레이드, **8초마다 레벨 × 2개**를 건설하는 자동 작업자
- 완성된 높이까지 올라가는 전망대, 현장 복귀
- 기여한 플레이어 모두에게 완공 보상, 35초 후 다음 공사
- 한국어 HUD, 터치 화면 레이아웃, 완료 효과
- 서버에서 거리·쿨다운·금액 검증
- 개인 기록 자동 저장: 게시된 실제 서버에서 세션 잠금과 `UpdateAsync` 사용

Studio와 게시 전 로컬 파일은 연습 모드입니다. 종료하면 초기화되며 실제 저장소에 접근하지 않습니다. 실제 서버에서는 코인, 업그레이드, 누적 기여도와 완공 횟수가 저장됩니다. **타워 건설 단계는 서버별 한 라운드의 상태**이며 서버가 종료되면 초기화됩니다. 오프라인 자동 수익은 없습니다.

## 제작·검증

```sh
./scripts/build.sh       # Rojo로 .rbxlx 재생성
./scripts/test.sh        # 실제 Studio 서버/클라이언트 플레이 테스트
./scripts/test.sh --multi # 실제 Studio 클라이언트 2개로 협동 테스트
./scripts/test.sh --sabotage # 2인 빼돌리기·쓰레기통·피격 취소·건설 차감 검증
lua tests/profiles_mock.lua # 저장소 모형을 사용한 저장/동시접속 검증
lua tests/prank_inventory_mock.lua # 결제 중복, 저장 실패, 재접속, 사용권 검증
./scripts/preview.sh     # 완성된 월드의 편집 미리보기 열기
```

`preview.sh`로 연 편집 화면을 **File → Save to File**로 저장하면 파일에 미리보기 월드가 포함됩니다. `build.sh`는 코드만으로 재생성하므로 이후에도 Play를 누르면 전체 월드가 정상 생성됩니다.

필요한 도구: Rojo 7, Roblox Studio. 빌드 스크립트는 macOS zsh 기준입니다. 일반적인 Windows 환경에서는 프로젝트 폴더에서 `rojo build default.project.json --output dist/Build-the-Burj.rbxlx`를 사용할 수 있습니다.

## 자신의 Roblox 경험에 올리기

1. 자신의 Creator Hub 계정에서 새 경험을 만들고, 빌드한 파일을 Roblox Studio에서 게시합니다.
2. 자신의 경험에 뺨때리기·빠따·바나나 Developer Product를 만들고, `src/shared/PrankCatalog.luau`의 `ProductId`를 교체합니다. 기존 ID는 원래 경험에 종속되어 있으므로 포크한 경험에서는 사용할 수 없습니다. Studio의 무료 체험은 상품 설정 없이 테스트할 수 있습니다.
3. `scripts/publish_existing.luau`를 사용할 경우, 파일 안의 Universe ID와 Place ID를 자신의 경험 값으로 교체합니다.

실제 서버의 DataStore 저장과 실물 휴대폰 조작은 최종 검증 기록에 포함되지 않았습니다. Roblox 제공 기능과 외부 아바타·자산은 각 제공자의 이용 조건을 따릅니다.
